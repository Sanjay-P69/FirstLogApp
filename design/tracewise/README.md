# Tracewise icon

An original native vector mark: a conversation outline contains a connected
activity trace ending at an insight node. It is a product identifier, not a claim
that the planned AI features have shipped. No reference branding/assets were copied.

The editable sources are `icon.svg` and `icon-round.svg`. Android foreground and
monochrome vectors use the same path geometry in a 108 × 108 viewport. The mark is
kept around the central adaptive-icon safe area. The solid background is petrol
(`#123F46`), with ivory (`#F6F4E9`) and a mint focal node (`#A8E2C7`). The monochrome
variant uses a single white mask for system tinting.

The `mipmap-*` PNGs cover 48, 72, 96, 144, and 192 pixels, including round versions
for Android 7. Adaptive icons cover Android 8+, with a monochrome layer for themed
launchers. `ic_firstlog_logo` retains its resource name for compatibility but shows
the new mark. `icon-preview.png` is a rendered preview of the SVG source.

Created by editing SVG/Android vector assets directly and rendering with Sharp;
no image-generation model was used. Check installed launcher masks and themed
icons on a real device before treating launcher appearance as fully verified.
